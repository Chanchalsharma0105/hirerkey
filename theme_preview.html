View 2 Sidebar Micro-Interaction Breakdown:
  • Spring-Loaded Indicator: ::before pseudo-element transforms with scaleY(0) → scaleY(1) using spring easing cubic-bezier(0.34, 1.56, 0.64, 1).
  • Smooth Label Translation: Content slides smoothly translateX(4px) to make room for the indicator bar.
  • Dynamic Icon Rotation: Icon scales to 1.15, rotates -3deg, and gains a purple drop-shadow rgba(124, 58, 237, 0.22).
  • Active State Anchoring: Active item has solid theme purple color (#7C3AED), rgba(124, 58, 237, 0.06) tint background, and 26px solid indicator bar.
  • Collapsed Rail Squircle: When collapsed to 68px rail, active item morphs into a glowing purple squircle card (linear-gradient(135deg, #7C3AED, #6D28D9)) with 12px border radius.
